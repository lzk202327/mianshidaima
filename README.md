## 运行环境
- 微信开发者工具 Stable 2.02+
- 基础库 2.0+
- 无需后端/数据库（数据存本地缓存）
- 编译设置：✅ 将 JS 编译成 ES5 / ✅ 过滤无依赖文件

## 安装与启动步骤
1. 克隆仓库：
   git clone https://github.com/lzk202327/mianshidaima.git
2. 打开微信开发者工具 → 导入项目 → 选择克隆的文件夹
3. AppID 选"测试号"
4. 点击编译，模拟器即可运行
5. 点击"预览"扫码，真机测试震动和提醒

## 测试数据生成
运行后进入"控制页"，输入药名、选择时间、点添加，数据自动存本地缓存。

## 主要功能入口
- pages/control：药品录入、删除、定时提醒（弹窗+震动）
- pages/status：健康数据录入展示
- pages/notice：服药通知展示

## 已知限制
- 小程序关闭后无法提醒（需服务端支持）
- 数据仅存本地，换设备需重新录入
- 震动在模拟器无效，需真机测试
